# 🤖 Gen AI Chatbot Mentor Project  

This project is an **Agentic AI–based Chatbot Mentor** built to guide users in learning, problem-solving, and concept understanding.  
It uses **agentic reasoning** to behave like a mentor—analyzing user intent and providing structured, step-by-step explanations instead of simple replies.

## 🔍 Project Workflow
1. **User Input** – The user enters a question or learning request.  
2. **Query Understanding** – The agent analyzes intent and context.  
3. **Agentic Reasoning** – The system plans how to respond using reasoning steps.  
4. **Knowledge Invocation** – Relevant knowledge or tools are applied if required.  
5. **Response Generation** – A clear, mentor-style explanation is generated.  
6. **User Interaction** – The response is displayed in real time via the app.  

---

## 🚀 How to Run the Project
1. Clone the repository.  
2. Install required dependencies using `requirements.txt`.  
3. Add your API key using a `.env` file or Streamlit secrets.  
4. Run the application:  
   - With **Streamlit** → `streamlit run app.py`  
5. Interact with the chatbot mentor through the browser.
